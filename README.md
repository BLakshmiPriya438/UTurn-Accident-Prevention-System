# U-Turn Accident Prevention System

## Overview
This project is designed to reduce accidents at blind U-turns by detecting approaching vehicles using ultrasonic sensors. When a vehicle is detected within a predefined distance, the system activates warning indicators to alert drivers from the opposite direction.

## Components Used
- Arduino UNO
- Ultrasonic Sensor (HC-SR04)
- LED
- Buzzer
- Jumper Wires
- Breadboard

## Technologies Used
- Embedded C
- Arduino IDE

## Features
- Vehicle detection using ultrasonic sensor
- Automatic warning indication
- Real-time obstacle monitoring
- Low-cost road safety solution

## Working
The ultrasonic sensor continuously measures the distance of approaching vehicles. When a vehicle is detected within the set threshold distance, the Arduino turns on the LED and buzzer to warn drivers at the blind U-turn, helping reduce the risk of collisions.

## Applications
- Blind road turns
- Mountain roads
- Highway intersections
- Smart transportation systems
